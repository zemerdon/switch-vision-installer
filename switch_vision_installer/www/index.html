Update All uses the safe dependency order: Core → Discovery → SNMP2MQTT → UniFi2MQTT. Optional UniFi2MQTT is never installed automatically. Installer updates are applied from Home Assistant Settings → Apps.

Core install or reinstall

The Core installer runs preflight checks, verifies the public release and checksum when published, creates and validates a backup before changes, replaces only changed Core/frontend files, and preserves custom logos and faceplates.

Home Assistant Core restarts only when you select its action button. Repository-managed apps are updated through Supervisor by their component Update buttons or Update All.
