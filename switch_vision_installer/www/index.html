Install or update

The installer runs preflight checks, verifies the public release and checksum when published, creates and validates a backup before changes, replaces only changed components, preserves custom logos and faceplates, and protects Discovery and SNMP2MQTT configuration.

Home Assistant Core and Discovery are restarted only when you select the post-install action buttons.
